############
Installation
############

Python & OS Support
###################

PyDocX is supported and tested with CPython versions 2.6, 2.7, 3.3, 3.4, and
PyPy 2.5 (Python 2.7 compatible). These are the versions exercised by the
CI matrix (see ``.travis.yml`` and ``tox.ini``); other Python versions may
work but are not officially tested.

PyDocX is supported and tested with Linux and Windows.

Install using pip
#################

.. code-block:: shell-session

    $ pip install pydocx

Upgrade using pip
#################

.. code-block:: shell-session

    $ pip install -U pydocx
